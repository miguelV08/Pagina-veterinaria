**feat: implementar política de tratamiento de datos, recuperación de contraseña y funcionalidades del rol usuario**

Se implementaron nuevas funcionalidades en la plataforma web de la veterinaria con el objetivo de mejorar la experiencia de navegación, facilitar la gestión de citas y brindar a los usuarios un acceso más completo a los servicios ofrecidos por la clínica veterinaria.

**1. Política de tratamiento de datos personales**
- Se agregó una sección para consultar la política de tratamiento de datos personales de la veterinaria.
- Se incorporó el contenido relacionado con el manejo, la protección y el tratamiento de la información personal de los usuarios.
- Se facilitó el acceso a esta información desde la plataforma para que los usuarios puedan conocer las condiciones bajo las cuales se gestionan sus datos.

**2. Recuperación de contraseña**
- Se implementó la funcionalidad de recuperación de contraseña para los usuarios que no recuerden sus credenciales de acceso.
- Se agregó la interfaz correspondiente para iniciar el proceso de recuperación.
- Se mejoró la accesibilidad al sistema de autenticación, permitiendo que los usuarios puedan recuperar el acceso a sus cuentas de manera más sencilla.

**3. Creación del rol de usuario**
- Se creó el rol de usuario dentro de la plataforma, con funcionalidades orientadas a la autogestión de los servicios veterinarios.
- Se habilitó una interfaz para que los usuarios puedan consultar y administrar sus citas.
- Se organizó el acceso a las diferentes opciones disponibles según las necesidades del usuario.

**4. Consulta de ubicación de la veterinaria**
- Se agregó una funcionalidad para consultar la ubicación física de la veterinaria.
- Se facilitó el acceso a la información de localización del establecimiento desde la plataforma web.
- Se mejoró la experiencia de los usuarios al permitirles identificar dónde se encuentra ubicada la clínica para acudir a sus citas presenciales.

**5. Gestión de citas veterinarias**
- Se implementó la funcionalidad para agendar nuevas citas veterinarias.
- Se agregó la opción de reprogramar citas previamente registradas, permitiendo modificar la fecha u horario según las opciones disponibles.
- Se habilitó la opción de cancelar citas cuando el usuario ya no requiera asistir.
- Se organizaron las opciones de gestión para facilitar el seguimiento y la administración de las citas desde la cuenta del usuario.

**6. Sistema de notificaciones**
- Se agregó una sección para consultar las notificaciones generadas por la plataforma.
- Se facilitó el acceso a información relevante relacionada con las citas y las novedades del servicio.
- Se mejoró la comunicación entre la plataforma y los usuarios mediante la centralización de las notificaciones disponibles.

**Resultado del desarrollo:**

Con estos cambios, se amplían las funcionalidades de la plataforma web de la veterinaria, incorporando herramientas de acceso y recuperación de cuentas, consulta de información institucional, gestión autónoma de citas y visualización de notificaciones. Estas mejoras contribuyen a una experiencia de usuario más organizada, accesible y eficiente, y permiten avanzar en la construcción de un sistema integral para la atención veterinaria.
